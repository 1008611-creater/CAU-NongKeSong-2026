# 中国农业大学2026年首届农客松

本仓库集中存放首届农客松（Agrihackathon 2026）的公开资料，供参赛选手查阅和转发。

## 怎么报名

- 报名入口：ANS（<https://ans.cauai.fun>），报名、组队、领算力、交作品都在上面完成。
- 报名截止：**2026 年 11 月 19 日 18:00**。
- 选手群：扫 [ANS 公众号二维码](素材/04-二维码/ANS公众号二维码.png) 关注后，后台回复「进群」获取选手群二维码。
